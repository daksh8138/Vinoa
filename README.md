

# Vinoa

Transform images into ASCII art with an interactive, infinite canvas. Upload an image, customize its appearance, and export your creation in multiple formats.

## Features

- Drag and drop or paste images (`Cmd/Ctrl + V`)
- Infinite canvas with pan and zoom
- Customizable ASCII art generation
- Multiple character sets and adjustable resolution
- Image inversion support
- Export creations as PNG or SVG
- Copy generated artwork to clipboard
- Movable toolbar with snap zones
- Dark and light themes
- Keyboard shortcuts for common actions

## Tech Stack

- **Framework:** Next.js 16
- **Frontend:** React 19, TypeScript
- **Styling:** Tailwind CSS 4
- **Components:** shadcn/ui
- **Animations:** Motion

## Getting Started

### Prerequisites

- [Bun](https://bun.sh/) installed on your system.

### Installation

Clone the repository:

```bash
git clone git@github.com:daksh8138/vinoa.git
cd vinoa
```

Install dependencies:

```bash
bun install
```

Start the development server:

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
